## Decisions made along the way (not all in the spec)

- **Phase 2b folded into phase 4.** Chats are not moved from notebooks to books; agent chats are new tables (`agent_chats`, `agent_messages`) bound to books. The old notebook chat keeps working until the notebook UI is retired.
- **Review mode default:** agent writes apply immediately with per-turn undo; review mode is opt-in (spec "Resolved decisions").
- **App metadata in frontmatter is flat and JSON-quoted** (`origin-type: "file"`); nested maps fail `story validate`. There is no app `id` key; identity is the book-relative path.
- **Agent `run_story` allowlist** excludes `init`, `import`, `migrate`, `compare`, and `similarity` (the last two take arbitrary paths).
- **Skills installed from story-skills** use a dedicated `{ type: 'story-skills', package: 'story-skills@<version>', skillId }` origin, distinct from the legacy starter catalog.

## Remaining work, in order

### 1. Agent tab follow-ups

- Pinned files: "Ask the agent" names the file in the draft (`?about=<path>`). Add `pinnedPaths` to the send schema if the agent should get file contents up front.
- The running turn is held per book in the browser tab. Another tab or device sees a running turn only by polling (`streaming` status) and cannot stop it.
- Review mode: search on the staged copy is a substring scan, not FTS5; `story build`/`export` are refused in review mode. Custom agents cannot pick a model (ADR 0013).

### 2. Retire the notebook era

- Run `NotebookMigrationService.migrateAll()` once at startup (or behind a one-time UI prompt), show its report, rename `data/notebooks/` to `data/notebooks.migrated/` (spec "Migration from notebooks").
- Presets: the agent uses only the default preset's generation controls, with the assistant prefill forced off (it breaks tool calling). When notebooks go, replace presets with agent generation settings (temperature, max tokens, thinking; optionally per custom agent), drop modules and prefill, keep old exchange snapshots readable. Needs an ADR superseding ADR 0009.
- Map notebook chats: decide whether to convert old chats into read-only agent chats or leave them viewable only in the migrated archive.
- Make `/books` the home route; remove notebook/source routes, services, UI, source categories/tags and bulk organize (ADR 0014 decision 8), and the `## Skills` injection path for books.
- Remove the jwynia starter set (`apps/server/skills-starter/`, its attribution, `starter-skills-content.test.ts`, `metadata.mode` handling). Keep `skill-creator` and `game-facilitator` in git history only (listed under roadmap "Later").
- Add a per-skill diff when the pinned story-skills version changes.

### 3. Series and the series bible (phase 5 in the spec)

- `data/series/<id>/` with `series-bible/` (a story-skills project) and sibling books; `SeriesService` with the identity/state field map (spec table), drift detection, push/pull/carry sync, `story init --follows/--precedes` for new books, series Health, and series-aware agent scope (`book` argument on file tools, `sync_series` tool). Layout was verified against the 0.18.0 CLI.

### 4. Exports and polish

- SillyTavern World Info lorebook and character-card exports from bible entities (spec "Exports"); `story build` formats in the Project tab (EPUB, DOCX, …) with downloads from `dist/`.
- Schema-driven frontmatter editors from `story-skills/schemas/story.schema.json` (today the editor is raw Markdown).
- Project zip import; diagrams (`story diagram` → Mermaid), knowledge views, `story context` previews; PWA install prompt tuned for phones.
